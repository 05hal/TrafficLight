# ViT 交通灯分类实验总结

## 模型信息

- **架构**: Vision Transformer (ViT-Base, patch16, 224x224)
- **预训练**: google/vit-base-patch16-224 (ImageNet-21k)
- **原理**: 自注意力机制，将图像切分为 16x16 patch 序列，通过全局注意力建模
- **与 CNN 的核心区别**: 无局部感受野/平移不变性归纳偏置，依赖数据驱动学习特征

## 超参搜索

在 4090 GPU 上完成 18/24 组配置搜索（因磁盘空间中断），**所有配置均达到 val_acc=1.0000**。

搜索空间:
- lr: [1e-5, 2e-5, 5e-5]
- epochs: [30, 50]
- weight_decay: [1e-4, 1e-3]
- aug_strength: [0.2, 0.4]

最优配置: lr=2e-5, epochs=30, weight_decay=1e-4, aug_strength=0.4

## 实验结果

### 实验 1: 原始设置（train_imgs 训练 → test_imgs 测试）

| 指标 | 值 |
|------|-----|
| 验证集准确率 | 100% (20张) |
| 测试集准确率 | **61%** (100张) |
| green 准确率 | 71% (30/42) |
| yellow 准确率 | 79% (31/39) |
| red 准确率 | **0%** (0/19) |

分析: 模型完全无法识别红灯，所有红色灯被误判为黄色。验证集100%是假象（仅4个红灯样本碰巧正确）。

### 实验 2: 加类别权重 + 加权采样

| 指标 | 值 |
|------|-----|
| 测试集准确率 | **51%** |
| 预测分布 | yellow: 88, green: 12, red: 0 |

分析: 类别权重过强导致模型崩塌，几乎所有样本被预测为黄色。

### 实验 3: 交换训练/测试角色（test_imgs 训练 → train_imgs 测试）

| 指标 | 值 |
|------|-----|
| 测试集准确率 | **41%** |
| 预测分布 | green: 100 |

分析: 模型预测全部为绿色，跨域泛化完全失败。

### 对比: ResNet18 基线

| 指标 | 值 |
|------|-----|
| 测试集准确率 | **86%** |
| 主要失败模式 | 过渡期颜色混淆 |

## 根因分析

### 1. 训练集质量低

- 100帧中存在大量近似重复帧（微小像素变化），实际独立样本可能仅 20-30 个
- 仅来自一个红绿灯，外观单一（灯型、亮度、安装角度、背景）
- 无自行车灯等变体

### 2. 跨域泛化失败

- 训练集和测试集拍摄于不同路口的不同红绿灯
- 灯型设计、光照条件、拍摄角度、背景环境完全不同
- 模型学到的是"这个特定灯的特征"而非"交通灯的普遍特征"

### 3. 标注风格不一致

- train_imgs: 小框，仅标注亮灯区域
- test_imgs: 大框，标注整个灯体
- 裁剪出的图片视觉特征差异大

### 4. 为什么 ViT 受影响比 ResNet18 更大

| 特性 | CNN (ResNet18) | ViT |
|------|---------------|-----|
| 归纳偏置 | 局部感受野 + 平移不变性 | 无，纯数据驱动 |
| 小数据表现 | 好，偏置提供先验知识 | 差，无法从少量数据学到有效模式 |
| 特征学习 | 局部颜色和边缘特征，恰好可迁移 | 全局注意力关系，需要大量多样化数据 |
| 泛化方式 | "红色圆形亮斑=红灯" 可跨灯迁移 | 全局上下文关系，高度依赖训练数据分布 |

## 核心结论

**ViT 的架构劣势并非固有，而是在小数据+低多样性条件下无法发挥优势。**

- ViT 在大规模多样化数据上碾压 CNN（这是业界共识）
- 但本项目训练集条件过于受限，ViT 的自注意力机制反而成为负担
- ResNet18 的 CNN 归纳偏置恰好提供了"颜色+形状"的先验知识，适合这种简单分类任务
- 这体现了模型选择需要匹配数据条件的原则

## 改进方向（若数据条件允许）

1. 合并 train_imgs + test_imgs 共同训练，增加数据多样性
2. 增加更多不同路口、不同天气、不同时段的数据
3. 使用 CLIP 零样本分类（不依赖训练数据，通过文本描述直接分类）
4. 加入时序信息（VideoMAE / CNN+LSTM），利用交通灯状态变化的有序性
